# Student CRUD API

A RESTful Student CRUD API built using FastAPI, SQLAlchemy, SQLite, and Pydantic.

## Features

- Create Student
- Get All Students
- Get Student by ID
- Update Student
- Delete Student
- SQLite Database
- SQLAlchemy ORM
- Pydantic Validation
- Swagger UI Documentation

## Technologies

- FastAPI
- SQLAlchemy
- SQLite
- Pydantic

## Run the Project

```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Open:

http://127.0.0.1:8000/docs
